# Code of conduct

This is a small hobby project about a tool for running pretend-elf games. Nothing here is worth being unpleasant over.

## The short version

- Be decent. Assume good faith — most disagreements here are about tradeoffs, not malice.
- Disagree with ideas, not people. "This approach has a problem" is fine; personal attacks, harassment, and put-downs aren't.
- Keep it on-topic. Issues and PRs are for the project; take unrelated arguments elsewhere.

## Reporting a problem

If someone's behaviour in an issue, PR, or discussion crosses a line, open an issue tagged for the maintainer's attention, or contact the repo owner directly through their GitHub profile if it needs to be private. Reports will be handled quietly and taken seriously.

## Consequences

Comments that violate this get edited or removed. Repeated or serious violations get the person blocked from the repo. That's it — there's no tribunal, just a maintainer trying to keep a small project pleasant to work on.
